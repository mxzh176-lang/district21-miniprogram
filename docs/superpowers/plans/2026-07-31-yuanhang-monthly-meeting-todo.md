# Yuanhang Monthly Meeting Todo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure one Yuanhang todo on the fifth of each natural month with a title such as `远航八月例会+联谊`, while reusing the existing August meeting record.

**Architecture:** Implement identical pure monthly target builders for the cloud-function runtime and local mini-program fallback. The cloud automatic-todo pipeline will upsert the nearest non-past monthly target by deterministic ID, adopt the known legacy meeting row on the same date, preserve user-maintained/completion fields, and write an operation log for system creation or correction.

**Tech Stack:** WeChat Cloud Functions, CloudBase database, mini-program CommonJS utilities, Node.js built-in test runner.

## Global Constraints

- Classification is `审核安全`; the todo remains internal to `org_team_yuanhang`.
- The date is always the fifth day of the nearest non-past natural month in China time.
- The exact title format is `远航{中文月份}例会+联谊` with no quotation marks.
- Existing completion state, time, location, and description must not be overwritten.
- Existing role and todo write authorization is not broadened.
- Automatic create/update operations must be auditable.
- Any `cloudfunctions/` change requires redeploying the `api` cloud function; mini-program changes require uploading a new mini-program version.
