# 二十一协作区小程序 Demo 演示说明

## 开场

这是二十一协作区四个服务队共同使用的公益服务与发展档案平台。

四个服务队分别是：

- 领航服务队
- 爱领航服务队
- 远航服务队
- 精英服务队

当前约120名狮友，系统按照未来200人规模设计。

## 演示重点

### 1. 首页

首页不是新闻页面，而是当月工作台。

优先展示：

- 本月公益服务
- 狮友关爱
- 狮友生日
- 聚会联谊
- 会议和岗位交接

### 2. 公益档案

活动结束后形成永久事件档案，保存：

- 时间和地点
- 所属服务队
- 负责人和参与人员
- 活动过程
- 服务成果
- 活动照片

### 3. 狮友资源

内部可以按服务队、企业、行业和公益资源查找狮友。

个人手机、企业联系方式和关爱信息会分级授权，不会全部公开。

### 4. 发展历史

分别保存：

- 二十一协作区发展历史
- 领航服务队发展历史
- 爱领航服务队发展历史
- 远航服务队发展历史
- 精英服务队发展历史

### 5. 管理权限

成员首次使用授权码绑定身份，正式权限按照：

```text
成员 + 服务队 + 年度届次 + 岗位
```

进行分配。每年换届后，新岗位权限生效，上一届任职历史继续保留。
