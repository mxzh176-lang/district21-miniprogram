# 管理员授权操作说明

## 角色层级

| 角色 | 管理范围 |
|---|---|
| 超级管理员 | 协作区及所有服务队，负责设置其他管理员 |
| 协作区管理员 | 协作区及其下属服务队 |
| 服务队管理员 | 仅所选服务队 |
| 岗位负责人 | 仅年度授权的岗位档案 |
| 普通成员 | 只读允许查看的内容 |

## 设置超级管理员和组织管理员

1. 被授权人先用自己的微信打开一次小程序。
2. 被授权人进入“我的”，复制页面上的账号编号并发给超级管理员。
3. 超级管理员进入“我的 → 权限中心 → 用户与管理员”。
4. 选择用户。
5. 选择角色：超级管理员、协作区管理员、服务队管理员或普通成员。
6. 选择管理范围并保存。
7. 被授权人重新进入小程序，权限立即生效。

系统不允许取消最后一名超级管理员，避免所有人失去管理入口。

## 设置岗位负责人

1. 进入“我的 → 权限中心 → 管理岗位”。
2. 选择协作区或服务队。
3. 选择岗位和负责人。
4. 设置开始日期与结束日期。
5. 保存授权。

岗位授权到期后自动失效。换届时为新负责人建立新任期，旧负责人将在新任期开始时失去对应岗位维护权限。
