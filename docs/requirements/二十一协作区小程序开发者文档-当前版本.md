## 1. 产品定位

21纪事本是二十一协作区及领航、爱领航、远航、精英四个服务队内部使用的组织协作、岗位授权、档案、历史事件、待办、成员和荣誉管理小程序。

产品边界固定为“内部组织管理工具”，不提供公开发帖、评论、关注、聊天、论坛、陌生人互动或开放式用户生成内容。任何新功能都必须先满足微信个人主体小程序审核要求。

## 4. 架构边界

页面调用链：

```text
pages
  -> miniprogram/utils/api.js
      -> miniprogram/services/organization-service.js
      -> miniprogram/services/event-service.js
      -> miniprogram/services/user-service.js
      -> miniprogram/services/honor-service.js
      -> miniprogram/services/platform-service.js
          -> cloudfunctions/api/index.js
```

硬性约束：

- 页面不得直接调用 `wx.cloud.database()`。
- 页面不得直接拼接云存储 `cloudPath`。
- 页面统一走 `api.call(...)`。
- 权限显示统一使用 `miniprogram/utils/permission.js`。
- 写操作必须由 `cloudfunctions/api/index.js` 再次鉴权。
- 图片和文件上传必须走 `miniprogram/services/file-upload-service.js` 的 `uploadOrgFile(params)`。

## 6. 档案与历史事件模型

当前核心集合：

```text
event_record
event_image
file_records
```

设计原则：

- `event_record` 是档案和历史事件的统一主记录。
- 历史事件不是重复录入，而是档案记录的展示视图。
- 图片不直接塞进主记录，图片走 `event_image` 与 `file_records`。
- 首页“最新归档”、档案页“最新归档”、历史事件列表和事件详情都应引用同一套档案事件数据。

常用字段：

```text
id / _id
organizationId
categoryId
positionId
eventDate / date
title
location
participantCount
participants
summary
content
ownerName / uploadedBy
status
eventStatus
honorStatus
images / photos
```

## 8. 栏目负责人授权

位置：

```text
miniprogram/pages/archive/position-edit/
cloudfunctions/api/index.js
```

当前逻辑：

- 管理员点击哪个栏目“编辑”，页面自动带入哪个职务。
- 职务名称只读，不允许手工乱填。
- 文档负责人从成员页名单中选择。
- 服务队页面只显示当前服务队成员。
- 二十一协作区页面显示协作区全员。
- 保存后写入 `role_assignment`，负责人获得对应栏目维护权限。

允许修改负责人角色：

- `super_admin`
- `region_admin` / `area_admin`
- `team_admin`

## 12. 文件与图片上传

必须使用：

```js
const { uploadOrgFile } = require('../../services/file-upload-service')
```

禁止页面直接：

- 调用云存储上传。
- 拼接 `cloudPath`。
- 把图片数组直接长期塞进事件主表。

上传成功后必须同步写入 `file_records`，并与事件通过 `event_image` 关联。

## 15. 发布与审核底线

每次提审前检查：

- 不存在 AI 助手入口。
- 不存在公开发帖、评论、论坛、聊天、关注、粉丝等社交能力。
- 不存在审核时隐藏、上线后开放的双版本逻辑。
- 普通成员不能看到新增、编辑、删除、授权等管理入口。
- 云函数能拒绝越权写入。
- 服务队之间数据隔离。
- 不采集身份证、人脸、手机号等非必要敏感信息。
- 账目仅内部查看与受控维护，不提供支付、募捐或交易。
- 本次如改动 `cloudfunctions/`，必须部署 `api` 后再测试。

审核说明建议写法：

```text
本小程序为二十一协作区及下属服务队内部组织管理工具，
用于岗位资料、内部档案、历史事件、待办和成员信息维护。
不提供公开发布、评论、聊天、论坛、关注、交易、支付或募捐功能。
```
