# 二十一协作区微信小程序 Demo

根据《二十一协作区微信小程序开发需求文档》制作的现场演示版本。

## Demo 特点

- 不依赖服务器、数据库、云开发或网络
- 导入微信开发者工具即可直接运行
- 使用本地模拟数据，不包含真实成员隐私
- 展示二十一协作区及领航、爱领航、远航、精英四个服务队

## 产品边界

本项目是约 120—200 人使用的公益服务档案与协作工具，不按大型会员办公系统设计。

- 保留：月度日历、协作待办、生日关爱、四队展示、公益活动、照片档案、成员企业资源、发展历史和年度岗位权限。
- 不展示：会员编号、捐款金额、积分、服务时长、培训时长、勋章、入会审批、稿件投稿和报表中心。
- 参考同类小程序时，只借鉴清晰的卡片、日历和组织展示方式，不照搬绩效管理功能。

## 已展示功能

- 首页月度待办：公益服务、狮友关爱、生日、联谊和岗位交接
- 月度日历和待办筛选
- 公益服务事件档案
- 活动详情和照片墙效果
- 四队筛选
- 狮友个人、岗位、企业和公益资源
- 协作区及服务队发展历史
- 通知公告
- 管理后台数据看板
- 成员授权码效果
- 年度届次与岗位授权
- 管理员操作日志

## 微信开发者工具导入

项目目录：

```text
C:\Users\Administrator\Documents\对话\yuanhang-miniprogram-new
```

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 选择本目录。
4. AppID 已写入 `project.config.json`。
5. 点击编译即可查看。

## 建议演示顺序

1. **首页**：介绍四队、120名狮友和六月重点待办。
2. **待办**：切换公益服务、关爱、生日和联谊分类。
3. **档案**：选择不同服务队，打开“圆梦助学”查看事件和照片墙。
4. **狮友**：搜索或筛选服务队，展开成员企业资源。
5. **我的**：进入发展历史和通知公告。
6. **管理后台**：展示授权码、年度岗位和操作记录。

## 说明

当前是用于讨论需求和视觉效果的 Demo。正式开发时需要接入阿里云 API、MySQL、OSS、微信身份绑定、分级权限和真实照片上传。
